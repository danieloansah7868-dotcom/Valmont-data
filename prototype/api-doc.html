Authentication

All requests require your API key in the Authorization header. Keys are issued per pricing tier and scoped to your account.

Authorization: Bearer vd_live_xxxxxxxxxxxxxxxx Content-Type: application/json

Endpoints

1 · Verify Number

POST/api/developer/verify
// Confirm a number is valid on its network before ordering { "network": "mtn", "number": "0241234567" }

2 · Purchase Data

POST/api/developer/purchase
// Place a single bundle order { "network": "mtn", "bundle_gb": 10, "number": "0241234567", "reference": "order-20260802-001" } // → 201 Created { "order_id": "VD-260802-4821", "status": "processing", "price": 40.50, "eta": "1h 52m" }

3 · Bulk Purchase

POST/api/developer/bulk
// Up to 200 orders in one call — max 1 per unique number { "orders": [ { "network": "mtn", "bundle_gb": 5, "number": "0241234567" }, { "network": "telecel", "bundle_gb": 20, "number": "0207654321" } ] }

4 · Order Status

GET/api/developer/order/{order_id}
// Status: processing → delivered | failed (auto-refunded) { "order_id": "VD-260802-4821", "status": "delivered", "delivered_at": "2026-08-02T16:35:00Z" }

5 · Delivery Tracker

GET/api/developer/tracker/{order_id}
// Full event timeline for your tracking UI { "events": [ { "ts": "14:02", "status": "paid" }, { "ts": "14:03", "status": "queued" }, { "ts": "15:55", "status": "delivered" } ] }

6 · Data Packages

GET/api/developer/packages?network=mtn
// Live bundle catalogue with your tier's prices { "network": "mtn", "packages": [ { "gb": 10, "price": 40.50, "expiry": "none" } ] }

7 · Balance & Result Checkers

GET/api/developer/balance
POST/api/developer/check-result
// Check wallet balance or verify a completed delivery (SMS/result checker)

8 · Withdrawal & Transactions

POST/api/developer/withdraw
GET/api/developer/transactions
GET/api/developer/usage-stats

9 · Webhooks

POSTyour-server.com/webhooks/vd (we call you)
// Registered via dashboard → webhook URL. Signed with HMAC-SHA256. { "event": "order.delivered", "order_id": "VD-260802-4821", "network": "mtn", "number": "0241234567", "ts": "2026-08-02T15:55:00Z" }

Code sample (JavaScript)

const res = await fetch("https://api.valmontdata.com/api/developer/purchase", { method: "POST", headers: { "Authorization": "Bearer vd_live_xxx", "Content-Type": "application/json" }, body: JSON.stringify({ network: "mtn", bundle_gb: 10, number: "0241234567" }) }); const order = await res.json(); // { order_id, status, price, eta }
